# CodeSip 鸿蒙客户端

本目录是独立 HarmonyOS Stage / ArkTS 工程，使用 ArkWeb 打开 CodeSip 的 HTTPS 阅读器，包含系统返回、错误重试、同源导航限制和 TLS 校验。账号、源码与笔记显示能力由同一阅读器提供。

用 DevEco Studio 打开本目录，下载适配 SDK 并配置本人签名后安装。项目不包含证书、私钥或用户数据。

当前工具环境提供 API 26 Beta SDK，目标为 API 26，最低兼容 API 12。已使用本机工具链完成签名构建；可在仓库根目录执行 `./scripts/build-harmony.ps1` 复现。2026-11-25 已核实真机运行 `online.ddyu.codesip` 0.1.3（10003），包含网络状态权限 `GET_NETWORK_INFO`，修复 ArkWeb 已联网却始终报告离线的问题。Web 阅读器由 HTTPS 服务加载，更新 Web 与后台无需重新安装 HAP；Web 更新使用头像菜单“检查应用更新”和“重载更新”；已缓存的页面与笔记可离线重开。签名材料与安装包仅保存在本机私有目录。

手机导入 ZIP、系统分享与插件下载仍需对应设备流程验证。本机笔记缓存、手动同步、离线重载及冷启动已经真机验证，结果见 `../docs/phone-localfirst-2026-11-25.md`。第一版优先从电脑端上传源码和安装 Obsidian 插件，手机阅读同一账号的数据。

## 七七网络适配（0.1.4）

0.1.4（10004）增加限定于 CodeSip 阅读器页面的原生网络桥。七七通过 HarmonyOS RemoteCommunicationKit 从本机直连用户配置的模型接口，网页端继续使用浏览器 fetch。API 密钥不存入原生配置，也不发往 CodeSip 服务端。

这项能力需要覆盖安装新 HAP，仅“重载更新”网页不能给 0.1.3 增加原生网络能力。使用同一签名的安装包执行 `hdc install -r <HAP路径>`，不要卸载或清除应用数据。当前产物和验证范围见 [鸿蒙七七连接修复](../docs/qiqi-harmony-2026-11-28.md)。本次构建成功不代表已经完成真机安装或验证。
