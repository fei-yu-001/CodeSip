# 阅读体验与文档编辑

## 阅读入口

- 批注、批注列表、编辑、阅读设置放在独立的底部操作栏，不随正文滚动，不遮盖末尾内容。
- 正文顶部移除主题按钮；阅读设置集中提供三种配色、14–22px 字号、紧凑/舒展行距和仅看代码。字号、行距、主题保存在本机。
- 保留浏览器原生长按选字。选段后点击批注会引用所选内容，没有选段时引用当前可见段落。已有批注可从底部列表进入编辑。
- 个人中心、顶部账号和侧栏使用项目已有的七七头像，账号名称保持实际登录名称。
- “连接 Obsidian”统一为“设置云端同步”，明确显示电脑 Obsidian → CodeSip 服务端 → 手机阅读的路径。生成连接信息后保留当前弹窗；失败重试复用刚创建的库。

## 编辑与原文

只有笔记库的 Markdown 文档提供正文编辑。用户修改的是独立的“我的编辑版”，电脑同步的源文件保持只读；可随时切换查看原文。电脑原文版本变化时显示提示，不自动合并或替换编辑版。导入的代码文件保持只读，不执行源码。

输入时即保存本机草稿，离开编辑器、换文件或重载后可继续。点击保存才上传到云端；离线失败提示草稿状态，不标记为已同步。支持下载 Markdown 备份。下载功能使用浏览器下载能力，鸿蒙 WebView 是否能交给系统下载需实机验证。

编辑器打开且有修改时阻止应用更新重载。关闭编辑器后，已成功落盘的草稿允许随更新重载恢复。空间不足时显示错误并阻止直接关闭编辑器，用户可先保存到云端或下载备份。自动登录过期保留按账号隔离的草稿；主动退出清除本机草稿和离线数据，并有明确文案。

## 数据边界

- SQLite 新增 `reader_document_copies`，主键为 `(library_id, path)`，通过库归属校验账号；删除库时级联删除。
- `GET /api/libraries/:id/document-copy?path=...` 返回编辑版或 `null`；源文件被同步删除后，已有编辑版仍可通过此接口取回。
- `PUT /api/libraries/:id/document-copy` 接收 `path`、`content`、`baseHash`、`expectedUpdatedAt`。首次保存版本为 `null`；其他写入须匹配已保存时间戳，冲突返回 409。
- `baseHash` 标记编辑版本源于哪一份原文。它不授权覆盖源文件，也不更改原文清单或同步 revision。
- 相同内容和 baseHash 的重试幂等；同毫秒连续写入的版本单调递增。冲突界面可查看云端正文，并明确选择保留本机或采用云端；再次冲突继续保护草稿。
- 仅允许网页登录会话访问，拒绝插件令牌和跨来源写入。单份最多 50 万字符且不超过 2 MiB，账号编辑版总量最多 32 MiB。
- 本机记录使用 `codesip:document:v2:<user>:<library>:<path>`，包含已缓存编辑版和待保存草稿。退出/卸载后迟到请求不再写回存储。
