# 七七阅读助手

手机底部菜单第三项、电脑侧栏的「七七」打开聊天面板；阅读页保留顶部快捷入口，所有入口共享同一聊天实例。阅读主题改从顶部「主题」按钮选择，保留三种配色。代码、笔记中的「七七」按钮引用选中片段（未选择时引用当前行或当前段）。在批注抽屉点击「问七七」，还会带入正在编辑的批注文字。引用先显示在输入区，点击发送后才请求 API。

在面板的「API 设置」首次打开时预填 `https://ai.ximupowers.tech/v1`，模型用下拉菜单选择：

- DeepSeek V4.1 Flash：`deepseek-ai/DeepSeek-V4.1-Flash-1017`
- GLM 5.3：`GLM-5.3`
- GLM 5.3 Flash：`zai-org/GLM-5.3-Flash`

密钥仍由用户在设置中填写，仓库只保存公开地址和模型 ID。已有自定义接口保持原配置；API 地址改为其他服务后，模型恢复为可输入的字段。「使用七七预设」或手动把 API 地址改到不同来源（协议、主机或端口）时，会清空原密钥与记住选项；同一服务内调整端点会保留密钥。

也可以填写其他兼容 OpenAI Chat Completions 的 API 地址、模型名称和密钥。地址支持服务商的基础路径（如 `https://provider.example/v1`）或完整的 `/chat/completions` 端点。无需密钥的本机服务可留空密钥。本机地址允许 HTTP，其他地址要求 HTTPS。

当前实现由浏览器直接连接提供的地址，因此服务需支持 CORS，并允许 `Content-Type`、`Authorization` 请求头。它没有服务器代理，也不支持仅提供 Anthropic Messages 或 Responses 协议的地址。保存配置不会发起模型请求或消耗生成额度。

密钥默认只在当前页面内存中保留；明确勾选「在此设备记住密钥」后，存入当前账号的浏览器本地存储。设置与对话不随笔记同步，退出账号时由现有清理流程清除。密钥只进入服务商请求的 Authorization 头，不进入消息、批注或错误提示。

聊天支持流式回答、停止、失败重试、20 段本机历史、Markdown 显示与复制。默认发送范围限于这段对话及手动添加的片段。有来源版本的引用可以勾选「本次允许读取这份原文」，让七七按需读取同一文件的更多行；授权只对本次发送生效，下一条未附引用的消息不会继承。不会搜索整个项目或自动读取其他笔记。长引用会提示截取，超长对话会要求新建对话。

有引用的回答可以「另存为批注」。用户可编辑批注草稿，点击「确认保存批注」才进入既有批注保存与同步流程。先保存在本机，点击项目的「同步」才上传。每次生成新的批注 ID，原批注和源文件保持不变，避免历史建议覆盖后来的修改。保存的引用遵循现有 2000 字上限，批注正文为 10000 字上限。对话保留所引片段及来源版本，不代表实时读取了该文件的新版本。

## 模块边界

`QiqiPanel.tsx` 管面板导航、输入和引用草稿；`QiqiSettings.tsx` 管设置表单与尚未保存的配置；`useQiqiChat.ts` 管对话历史、生成生命周期和账号清理；`qiqiChat.ts` 管数据、配置、校验和延迟加载；`qiqiAgent.ts` 通过 Pi Agent 管工具循环；`qiqiTransport.ts` 管兼容网关的流式协议；`qiqiReferences.ts` 管原文版本校验与按行读取；`qiqiProviders.ts` 只保存公开服务元数据。它们不依赖项目同步调度器或应用更新实现，更新保护通过通用的 `useUpdateGuard` 注册具体原因。

## Pi 阅读工具

对话执行层复用 Pi 的 `@earendil-works/pi-agent-core` 1.7.0，保留现有 React 面板、三个预设模型、API 设置和本机对话历史。没有新增后台 Node 服务，生产服务仍为 Rust。Pi 运行时在第一次请求时加载；兼容网关的传输层继续禁止携带 Cookie、跳转和 Referrer，并处理流中断、JSON 回包和长度限制。

首个工具 `read_reference` 仅能按行读取本条消息明确授权的引用文件。目标项目、路径、账号和 hash 由应用绑定，模型不能传入另一个文件路径。文件必须是文本且不超过 1 MiB；每次最多 160 行/12000 字，每次发送最多 3 次原文读取、4 次模型请求。参数严格校验，拒绝小数行号，避免 Pi 默认强制转换改变用户范围。版本变化后要求重新打开和引用；停止、关闭、退出账号都会取消未完成工作。工具不会读取批注草稿、编辑版或目录中的其他文件。

更多行会发送给当前 API，面板显示正在读取的路径/行号；新增内容仍作为待分析数据处理。模型服务需要支持 Chat Completions 的工具调用。普通聊天不发送工具声明，仍可用于不支持工具的兼容服务。没有用真实密钥对三款模型的工具调用进行付费验证，浏览器回归使用合成响应。

修改仍以回答中的建议呈现；用户可以编辑后另存为批注。当前不提供自动写回原文、任意文件操作、终端执行、全库检索或后台任务。Pi 提供通用循环，CodeSip 继续管理阅读、授权和存储。

官方项目核对和实施记录见 [Pi 接入记录](qiqi-pi-integration-2026-11-28.md)。随 Web 产物附带的 MIT 声明为 `web/public/licenses/pi.txt`。
