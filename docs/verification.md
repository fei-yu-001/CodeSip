## 部署验证

线上入口为 `https://codesip.ddyu.online`。CodeSip 使用独立的 `codesip.service`、系统用户、发布目录、SQLite 数据库、环境文件及 nginx 站点。

- 主页与健康接口返回 HTTP 200，健康接口标识为 `codesip`。
- 未登录访问项目接口返回 HTTP 401。
- 首次设置接口报告尚未创建账号；首次设置密钥仅保存在本机忽略目录及服务器私有配置中。
- Obsidian 插件下载包可下载并通过 ZIP 完整性检查。
- 现有游戏健康接口在发布前后均为 HTTP 200，两项服务均保持运行。
- 服务设置 384 MB 内存及 50% 单核 CPU 上限，SQLite 位于独立数据目录。
- 已通过 SQLite 在线备份接口创建首份备份，未自动配置定时备份。

最终发布标识与校验值见本文末尾的发布记录。

## 未完成的验证与功能边界

- 鸿蒙工程尚未签名和安装到手机；ArkWeb 的文件选择、下载、系统分享和离线存储需要真机验证。Web 版可以先从手机浏览器使用。
- 未向真实 Obsidian 库安装插件或上传真实笔记，需用户选择同步范围后试用。
- Safari/Firefox 采用磨砂降级，目前未完成实机验证。
- 符号速览是文本规则提取，尚无完整语义分析、定义/引用跳转或调用关系图。
- 双链仅实现基础文件跳转；公式、Mermaid、Canvas、Dataview、笔记嵌入和标题/块定位未实现。
- 当前为个人单账号服务，尚无公开注册、密码找回和端到端加密。
