# 阅读器更新验收 · 2026-11-23

本轮以前端 agy 的界面修改为基础，由 Codex 完成后台、同步状态、联调与发布验证。测试使用合成内容和临时数据库，没有修改用户原始代码或笔记。

## 本轮修复

- 批注写入独立 SQLite 表，按账号、库和文件隔离，支持编辑、删除和跨设备读取。
- 本机草稿与服务器状态分开显示；离线、响应丢失、旧请求延迟返回及多设备冲突不会直接覆盖草稿。
- 冲突要求用户选择版本；离线删除保留待处理记录，服务器确认后才清除。自动会话过期保留批注，主动退出明确提示清除本机副本与未同步草稿。
- 代码区占满可用宽度，换行开关生效，长文件可滚动到末尾；恢复阅读位置，避免快速刷新和卸载节点时误存零位置。
- Markdown 目录来自实际渲染的标题，支持重复标题定位和搜索结果指定行跳转。
- 统一浅色、松烟暖灰和羊皮纸主题；返回操作先关闭弹层或全屏代码，再执行页面导航。
- 头像和桌面退出按钮打开应用内账号弹窗；刷新显示加载状态，并更新批注。
- 错误处理器在注册路由前建立，静态托管时仍返回中文业务提示，内部错误统一隐藏详细信息。
