# 阅读空间、源码定位与项目导航验证

日期：2026-11-28。

## 改动

- 桌面进入阅读后收起全局主页侧栏，项目目录常驻；主题和账号入口保留在顶栏。缩小桌面顶栏和工具栏占高，代码视图限制在正文容器内，长行只在代码区滚动。
- 手机顶部使用明确的“目录”入口，另加底部目录快捷按钮；有代码批注时给快捷按钮留出空间，Markdown 底部操作仍可点击，专注模式隐藏这些导航。
- Markdown 阅读设置新增“舒适 / 铺满”，本机记住选择；单独查看代码块时也可利用可用宽度。
- CodeMirror 通过 Compartment 更新真实字号，以源码字符和它在屏幕上的位置维持视口。长行重新排版后再校正实际坐标，隐藏标签保留锚点，刷新优先恢复源码位置并兼容旧的像素进度。滚轮等用户输入优先于待处理的布局校正。退出账号或删除项目时不写回已清理的源码进度。
- 浅色语法通过 HighlightStyle 使用现有配色，深色保留 oneDark；选区、只读、折叠、批注及多文件挂载不因缩放重建。
- 支持 `#/code/...`、`#/notes/...` 项目链接，保留带问号的编码路径/标题。项目打开维持当前账号的缓存优先策略；缺少缓存时实际尝试请求，不被 WebView 不准确的 `navigator.onLine` 阻止。
- 未缓存项目的 404、网络失败和返回错误项目清单有持久反馈；提供“重试打开项目”和“回到项目列表”。过期请求不能覆盖新打开的项目，缓存写入仍受请求序号和账号隔离保护。

## 范围和限制

- 本轮手机验证是浏览器移动设备模拟，没有新增真机联调结果。
