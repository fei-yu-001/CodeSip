## 真实网关

2026-11-28 使用 Chromium 159.0.8154.6、合成无效 Key 发起跨域探测，未启用 trace，也未使用关闭 Web 安全的参数。OPTIONS 返回 204，Allow-Origin 和 Allow-Headers 均为 *；浏览器实际读取到 POST 的 HTTP 401。七七界面显示鉴权失败并允许重试或返回设置，合成 Key 未出现在页面文字或 localStorage 中。
