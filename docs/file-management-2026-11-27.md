# 文件与项目删除 · 2026-11-27

目录原来只能删除整个项目，单个文件缺少删除入口；重复项目也必须先打开目录才能清理。本轮增加文件删除，并把项目删除入口放到首页卡片。

## 操作

- 文件目录每行右侧增加垃圾桶，点击后显示完整路径与所属项目；确认才删除。正文阅读工具栏不增加按钮或高度。
- 首页每张项目卡片右下角可删除项目，空库同样支持；目录底部的删除项目入口保留。确认窗口显示名称、文件数和占用空间。
- 删除单个文件会移除 CodeSip 服务端文件及本机对应缓存、关闭该文件标签，保留其他打开文件、滚动位置和同内容文件的共享缓存。最后一个文件删除后项目仍保留，可重新导入。
- 单文件删除保留独立的批注与个人编辑版，以便同路径重新导入时恢复；删除整个项目则清除该项目的服务端阅读数据、本机草稿、离线缓存和标签。
- 电脑原文件不受影响。Obsidian 中仍存在且参与同步的文件会在下次上传时重新出现；完整 ZIP 再次导入同理。要从源头永久移除，应在源目录整理文件或调整同步范围。删除整个项目后原插件连接失效。

## 一致性与权限

新增 `DELETE /api/libraries/:id/file`，请求包含 `path` 与 `baseRevision`，返回更新后的完整目录。笔记和代码项目均支持；只允许浏览器会话调用，拒绝其他账号、插件令牌和跨来源写入。

Rust 在同一事务中校验归属、路径、版本并删除文件、更新统计和修订号、读取新清单。旧版本请求返回 409，窗口提示同步后重新确认；失败不会提前清空页面。数据库结构、插件同步协议不变。

成功删除后，本机以单个 IndexedDB 事务更新目录、项目卡片统计、完整离线标记，并清理无其他文件引用的内容缓存。删除项目只清理该项目的阅读队列和本机数据；服务端已经删除的项目也可以清除本机残留副本。
