# 阅读与项目更新修复 · 2026-11-27

本轮处理 ZIP 更新产生重复项目、Obsidian 常见排版缺失、代码字号不可调、切换文件销毁阅读现场四项反馈，并在已连接 HarmonyOS 手机联调。

## 行为变化

- **更新原项目**：导入窗口默认匹配同类型、同名称的项目，也可明确选择现有项目或“新建项目”；存在多个同名项目时必须选择目标。目录底部增加“更新项目内容”。上传完整 ZIP 后，原项目 ID 不变，文件以新 ZIP 为准，原文件批注、个人编辑版和阅读记录继续绑定原项目。已有重复项目不会自动合并或删除。
- **并发保护**：更新请求携带 `libraryId` 与 `baseRevision`，校验账号归属、类型与版本；冲突返回 409。Rust 在同一事务内替换文件清单，失败时回滚；不变更数据库结构或插件同步协议。原有 Obsidian 插件仍按路径更新同一笔记库。
- **笔记排版**：补上 `==高亮==`（可含加粗）、`%%隐藏注释%%`、普通换行、`![[图片|宽x高]]`，以及 `[[笔记#标题|别名]]` 的章节定位。注释不影响源行号，代码与公式中的标记保持原样；仍限制不可信 HTML。Callout、表格、公式、折叠 HTML 原有支持继续验证。Obsidian 第三方插件、主题 CSS、脚本视图不在兼容范围。
- **代码缩放**：代码页提供 A−、百分比重置、A+，字号 10–24 px，本机记忆；保留自动换行开关。调整字号不重建 CodeMirror。
- **多文件阅读**：标签可以切换和主动关闭，横向滚动适配手机。切换文件或返回首页保留已打开阅读器、滚动、折叠和组件状态；关闭标签才释放其阅读器。退出账号清空当前阅读工作区，删除项目只释放该项目标签。页面完全重载后仍使用既有单文件阅读位置恢复；本轮不将标签列表持久化到磁盘。Markdown 排版完成后释放 Worker，已排版页面保留。
